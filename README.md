# Hex Isle 3D

Settle the isle in 3D — solo vs AI, pass-and-play, or online multiplayer with room codes. Installable PWA.

## Publish on GitHub Pages

1. Open the repo **Settings → Pages**.
2. Under **Build and deployment**, set Source to **Deploy from a branch**.
3. Branch **main**, folder **/ (root)**, then Save.

The game will be at https://wilsonsamiano.github.io/hex-isle-3d/

On iPhone or iPad, open that link in Safari, tap Share, then **Add to Home Screen**.
